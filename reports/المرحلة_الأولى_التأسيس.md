# المرحلة الأولى: التأسيس (main)

**الفرع:** `main`  
**الوصف:** بناء هيكل المشروع الأساسي بالكامل

---

## الإنجازات

### 1. إعداد المشروع
- إنشاء مشروع Laravel من الصفر
- إعداد قاعدة البيانات وجميع الاتصالات
- إعداد Vite و Tailwind CSS
- تفعيل المصادقة (Authentication)

### 2. قاعدة البيانات - الجداول
| الجدول | الوصف |
|--------|-------|
| `users` | المستخدمين (بما فيهم الصيادلة والمشرفين) |
| `medicines` | الأدوية |
| `unit_types` | أنواع الوحدات (أقراص، عبوات، إلخ) |
| `stocks` | أرصدة المخزن لكل مستخدم/دواء/شهر |
| `invoices` | فواتير الصرف |
| `invoice_items` | أصناف الفواتير |
| `dispensed_medicines` | أدوية منصرفة (بدون فاتورة) |
| `notifications` | الإشعارات |
| `cache` / `jobs` / `sessions` | جداول النظام |

### 3. الموديلات (Models)
- `User` - مع صلاحيات `AdminMiddleware` لاحقاً
- `Medicine` - الأدوية مع `price_hotline` و `price_clinic`
- `Stock` - رصيد المخزن (`user_id`, `medicine_id`, `stock_date`, `quantity`, `is_init`)
- `Invoice` / `InvoiceItem` - الفواتير
- `DispensedMedicine` - أدوية منصرفة
- `UnitType` - أنواع الوحدات
- `StockInitialized` - إشعار ترحيل الرصيد

### 4. وحدات التحكم (Controllers)
| المتحكم | المهام |
|---------|--------|
| `AuthController` | تسجيل الدخول والخروج |
| `DashboardController` | لوحة التحكم الرئيسية |
| `MedicineController` | إدارة الأدوية (CRUD) |
| `StockController` | إدارة أرصدة المخزن |
| `InvoiceController` | إنشاء وعرض الفواتير |
| `DispensedMedicineController` | صرف أدوية بدون فاتورة |
| `ReportController` | تقارير شهرية + جرد المخزن |
| `UserController` | إدارة المستخدمين |
| `UnitTypeController` | إدارة أنواع الوحدات |
| `NotificationController` | عرض الإشعارات |

### 5. الخدمات والميزات
- **StockService** - خدمة ترحيل أرصدة المخزن شهرياً (تحتوي على مشكلة الـ Early Return التي تم إصلاحها لاحقاً)
- **InitializeMonthlyStock** - أمر Artisan (`app:initialize-stock`) يتم تشغيله أول كل شهر via Scheduler
- **Scheduler** - `routes/console.php`:
  - `app:initialize-stock` → أول كل شهر في منتصف الليل
  - Heartbeat → كل دقيقة لمراقبة عمل Scheduler
- **Notifications** - إشعارات ترحيل الأرصدة مع أسماء الأدوية والكميات

### 6. واجهات المستخدم
- صفحة تسجيل الدخول
- لوحة التحكم الرئيسية مع إحصائيات: عدد الفواتير، الأدوية المنصرفة من وإلى الفواتير
- صفحات إدارة: المستخدمين، الأدوية، أنواع الوحدات
- صفحة المخزن بإضافة وتعديل وحذف الأرصدة
- صفحة إنشاء الفواتير مع إضافة أصناف وإظهار السعر الإجمالي
- صفحة عرض الفاتورة
- صفحة صرف أدوية مع إضافة صفوف ديناميكية
- تقرير الجرد (Inventory Report) مع طباعة
- تقرير شهري (Monthly Report)

### 7. الـ Routes
- مصادقة: تسجيل دخول، تسجيل خروج
- Users CRUD
- Medicines CRUD + search
- Unit Types CRUD
- Stock CRUD
- Invoices: إنشاء، عرض، طباعة
- Dispensed Medicines: إنشاء، تحديث، حذف
- Reports: شهرى، جرد
- Notifications: عرض، علامات مقروءة
- Ajax: `/check-referral-number` (للتأكد من تكرار الرقم)

---
