**الفرع:** `seventh_update` (HEAD - الوضع الحالي)  
**الوصف:** إصلاح مشكلة ترحيل الرصيد الشهري، تعديل التقرير الشهري ثنائي الوضع، تحسين الطباعة

## الإنجازات

### 1. إصلاح مشكلة ترحيل رصيد المخزن 🔧 (أهم إصلاح)

**الملف:** `app/Services/StockService.php`

#### المشكلة القديمة:
```php
// السطر 46 - كان بيتحقق من أول سجل فقط
$stock = Stock::where('user_id', $user->id)
    ->where('stock_date', $monthDate)
    ->first();

if ($stock && $stock->is_init) {
    return;  // ← المشكلة: بيرجع خلاص ويسك步履 كل الأصناف التانية
}
```
- كان بيجيب **أول** سجل مخزن للشهر الجديد
- لو `is_init = true` للسجل ده → **يرجع على طول** ويسكب بقية الأصناف
- نتيجة لذلك: في أول كل شهر، كان بيرحل **صنف واحد بس** لكل مستخدم والباقي ضايع

#### الحل الجديد:
```php
// كل صنف بيتحقق لوحده
foreach ($previousStocks as $prevStock) {
    $currentStock = Stock::firstOrNew([...]);
    
    // سكيب بس للصنف اللي اترحل قبل كده
    if ($currentStock->exists && $currentStock->is_init) {
        continue;  // ← يكمل لباقي الأصناف
    }
    
    // ترحيل الرصيد
    $currentStock->quantity += $oldQty;
    $currentStock->is_init = true;
    $currentStock->save();
}
```
- إزالة الـ early return الخاطئ
- كل صنف يتعامل مع نفسه: لو مترحلش ← يترحل، لو مترحل قبل كده ← يتخطى
- إضافة تحقق `$currentStock->exists` لحماية الـ `firstOrNew` (عدم تطبيق `is_init` على كائن جديد)

### 2. التقرير الشهري - وضعين للعرض (Dual Mode)

**الملف:** `app/Http/Controllers/ReportController.php`

#### الوضع الأول: أيام الشهر
- للمستخدمين ذوي الكود `1111` (إسراء) و `2222` (ريم)
- الأعمدة = أسماء أيام الشهر بالعربية (كما في المرحلة السادسة)

#### الوضع الثاني: الأرقام التكرارية
- لبقية المستخدمين (الصيادلة)
- الأعمدة = الأرقام التكرارية (كما في المراحل الأولى)
- GROUP BY: `medicine_id, referral_number`

**المنطق:**
```php
$useDayNames = in_array($user->employee_code, ['1111', '2222']);
if ($useDayNames) {
    // GROUP BY medicine_id, dispense_date
    // columns = أيام الشهر
} else {
    // GROUP BY medicine_id, referral_number
    // columns = الأرقام التكرارية
}
```
- متغير `$dates` → أصبح `$columns` (قابل للتبديل)

### 3. تحسين طباعة الفاتورة - تقليل المسافات

**الملف:** `resources/views/invoices/print.blade.php`

- تصغير الشعار من `70x70` → `55x55`
- تصغير الخطوط (العنوان من `16px` → `14px`)
- تقليل الهوامش (footer margin-top من `40px` → `25px`)
- تقليل padding الخلايا من `6px` → `1px`
- إزالة ألوان الخلفية الزائدة (`background: #fff` المكررة)
- `@page` margin من `5mm` → `0`
- عرض الصفحة من `640px` → `620px`

**النتيجة:** فاتورة طباعة أكثر Compact ومحتوى أكبر في مساحة أقل
