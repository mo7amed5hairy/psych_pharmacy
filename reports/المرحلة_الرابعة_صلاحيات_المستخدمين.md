# المرحلة الرابعة: نظام صلاحيات المستخدمين

**الفرع:** `fourth_update`  
**الوصف:** إضافة صلاحيات تفصيلية للمستخدمين وإصلاح مسار الحذف

---

## الإنجازات

### 1. نظام صلاحيات تفصيلي (User Permissions)
**ملفات جديدة:**
| الملف | الغرض |
|-------|-------|
| `app/Models/UserPermission.php` | موديل الصلاحيات |
| `app/Http/Controllers/PermissionController.php` | تحكم صلاحيات |
| `app/Http/Middleware/CheckPermission.php` | ميدلوار التحقق من الصلاحية |
| `resources/views/permissions/index.blade.php` | واجهة إدارة الصلاحيات |
| `database/migrations/..._create_user_permissions_table.php` | جدول الصلاحيات |

### 2. جدول `user_permissions`
- `id`, `user_id`, `permission_name` (نص), `created_at`, `updated_at`
- كل صلاحية مخزنة كـ string (مثل `'invoice_list'`, `'report_monthly'`, إلخ)
- مرن：يمكن إضافة أي صلاحية جديدة بدون تعديل قاعدة البيانات

### 3. الصلاحيات المتاحة
| الصلاحية | الوظيفة |
|----------|---------|
| `invoice_list` | عرض قائمة الفواتير |
| `invoice_create` | إنشاء فاتورة |
| `stock_manage` | إدارة المخزن |
| `medicine_search` | البحث في الأدوية |
| `report_monthly` | التقارير الشهرية |
| `report_inventory` | تقرير الجرد |
| `dispensed_manage` | إدارة الصرفيات |
| `notification_view` | عرض الإشعارات |
| `user_manage` | إدارة المستخدمين |
| `permission_manage` | إدارة الصلاحيات |

### 4. ميدلوار `CheckPermission`
- `app/Http/Middleware/CheckPermission.php`
- يتحقق من وجود الصلاحية المطلوبة للمستخدم الحالي
- يقبل اسم الصلاحية كـ parameter: `->middleware('permission:invoice_list')`

### 5. واجهة إدارة الصلاحيات
- صفحة `/permissions` لعرض صلاحيات كل مستخدم
- جدول بجميع المستخدمين مع checkboxs للصلاحيات
- إضافة/إزالة صلاحيات لكل مستخدم (تحديث فوري)

### 6. حماية الـ Routes بالصلاحيات
- كل Route أصبح محمياً بصلاحية معينة:
  - `invoices.*` → `permission:invoice_list`
  - `stocks.*` → `permission:stock_manage`
  - `medicines.search` → `permission:medicine_search`
  - `reports.monthly` → `permission:report_monthly`
  - `reports.inventory` → `permission:report_inventory`
  - `dispensed-medicines.*` → `permission:dispensed_manage`
  - `notifications.*` → `permission:notification_view`
  - `users.*` → `permission:user_manage`

### 7. إصلاح مسار Destroy للصرفيات
- إصلاح Route `/dispensed-medicines/{dispensedMedicine}` بحذف DELETE
- إصلاح `DispensedMedicineController@destroy` ليعمل بشكل صحيح

### 8. إضافة خاصية `permissions` لموديل User
```php
// User.php
public function permissions()
{
    return $this->hasMany(UserPermission::class);
}
public function hasPermission($permissionName)
{
    return $this->permissions->contains('permission_name', $permissionName);
}
```

### 9. ربط الصلاحيات بالقائمة الجانبية
- إخفاء/إظهار عناصر القائمة الجانبية حسب صلاحيات المستخدم
- كل مستخدم يرى فقط الصفحات المسموح له بها

---

**ملخص:** تم تطوير نظام صلاحيات متكامل من الصفر يشمل جدول صلاحيات مرن، وميدلوار للتحقق، وواجهة إدارة، مع حماية كل Route في النظام بصلاحية محددة.
