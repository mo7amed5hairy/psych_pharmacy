# المرحلة الخامسة: التقارير والفواتير المتقدمة

**الفرع:** `fifth_update`  
**الوصف:** إضافة تقارير جديدة، تحرير الفواتير، وإنشاء فواتير متعددة

---

## الإنجازات

### 1. التقرير اليومي (Daily Report) - جديد
**Route:** `GET /reports/daily`  
**الملف:** `resources/views/reports/daily.blade.php`

- اختيار تاريخ محدد (افتراضي: اليوم)
- جدول محوري (Pivot Table): **الصفوف** = الأدوية، **الأعمدة** = الأرقام التكرارية
- عرض الكميات المنصرفة من (DispensedMedicines + Invoices) لكل دواء/رقم
- عمود أخير لإجمالي كل دواء
- زر **طباعة**: نافذة طباعة منفصلة
- زر **Excel**: تصدير إلى ملف Excel (.xls)
- تنقل بـ Enter بين الحقول

### 2. تقرير العيادة الخارجية (Clinic Report) - جديد
**Route:** `GET /reports/clinic`  
**الملف:** `resources/views/reports/clinic.blade.php`

- اختيار شهر وسنة
- عرض الأدوية المنصرفة مع: اسم الدواء، الوحدة، سعر الوحدة (`price_clinic`)، الكمية، الإجمالي
- **بطاقات إحصائيات:**
  - 💰 الإجمالي المالي (أزرق)
  - 📅 عدد أيام الصرف (أصفر)
  - 🎫 عدد التذاكر/الأرقام التكرارية (أخضر)
- زر **طباعة**: نموذج A4 احترافي مع:
  - شعار جامعة عين شمس
  - عنوان "العيادة الخارجية - أسعار الأدوية"
  - جدول بحدود 2px
  - مساحات توقيع (مديرة الصيدلية + رئيس مركز الطب النفسي)
- تنقل بـ Enter بين الحقول

### 3. تحرير الفواتير (Invoice Edit) - جديد
**Route:** `POST /invoices/{invoice}/update`  
**الوظيفة:** تعديل الفاتورة بالكامل

- **مودال (Modal)** في صفحة عرض الفواتير
- تعديل: اسم المريض، الرقم التكراري، تاريخ الفاتورة
- تعديل الأصناف: إضافة/إزالة/تغيير الكمية والسعر
- **ضبط المخزن تلقائياً:**
  - إعادة الرصيد للأصناف القديمة (إضافةquantity)
  - خصم الرصيد للأصناف الجديدة (طرح quantity)
  - التحقق من كفاية الرصيد قبل الحفظ
- حفظ عبر AJAX

### 4. إنشاء فواتير متعددة (Multi-Invoice Batch) - جديد
في صفحة إنشاء الفاتورة:

- زر "أضف فواتير اليوم" → تفعيل الوضع المتعدد
- إدخال عدد الفواتير وتاريخها
-生成 بطاقات فواتير متعددة ديناميكياً
- كل بطاقة: رقم تكراري، تاريخ، اسم مريض، بحث أدوية، جدول أصناف
- **إجمالي عام** لجميع الفواتير
- زر **"حفظ الكل"** → حفظ الفواتير تباعاً عبر AJAX

### 5. إزالة دمج الأدوية في الصرفيات
- قديماً: كان يتم دمج صفوف الدواء نفسه في الصرفية بجمع الكميات
- جديداً: كل صف يتم تخزينه كما هو بدون دمج

### 6. إزالة فحص الرقم التكراري الخاص بالمستخدم 2222
- إزالة الكود المخصص للمستخدم 2222 (هاجر) الذي كان يمنع تكرار الأرقام لها في نفس اليوم

### 7. القائمة المنسدلة للتقارير (Sidebar Dropdown)
- رابط "كشف المنصرف" أصبح قائمة منسدلة تحتوي على:
  - 📊 **شهري** - Monthly (موجود)
  - 📋 **يومي** - Daily (جديد)
  - 🏥 **منصرف العيادة** - Clinic (جديد)
- أيقونة شيفرون تدور عند الفتح/الغلق
- CSS للقائمة المنسدلة: `.sidebar-group-btn`, `.sidebar-dropdown`, `.chevron`

### 8. تنقل بـ Enter (Enter-Key Navigation)
إضافة في 8+ صفحات:
- عند الضغط على Enter: ينتقل التركيز للحقل التالي
- إذا كان هناك قائمة بحث مفتوحة: يختار أول نتيجة
- استثناء أزرار الحذف (`btn-danger`) والإضافة (`btn-primary`)

### 9. تحسينات عامة
- خيار "الكل" في DataTable Length Menu (`[[10, 25, 50, 100, -1], [10, 25, 50, 100, 'الكل']]`)
- `app.js`: إعداد Length Menu الافتراضي لكل DataTables
- تركيز تلقائي على حقل الكمية بعد اختيار دواء في المخزن والصرفيات
- السماح بكمية صفر (0) في أصناف الفاتورة (يتم تخطيها)
